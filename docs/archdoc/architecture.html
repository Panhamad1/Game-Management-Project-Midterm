System Architecture & Script Contracts

A complete technical breakdown of REBOUND's high-speed parkour, pneumatic physics, Spider-Sense threat detection, and 4-tier enemy AI in Unity. Explains how momentum sliding, grapple slingshotting, crate shielding, and bullet reflection connect cleanly without bugs.

The Four Clean Code Layers

The architecture is organized into four decoupled execution layers. Input and Spider-Sense warnings feed into ability calculations; ability calculations alter locomotion and physics bodies; physics bodies trigger environmental switches and defeat enemies; and time-trial managers track stage split times:

Physics Layer Setup & Collision Matrix

Setting up Unity Physics layers correctly prevents self-collision glitches and guarantees consistent raycast targeting:

Layer Name What Belongs on This Layer Behavior with Player Abilities & Locomotion
Layer 8: Player PlayerRoot capsule collider and ground sensors. Collides with Environment, Blocks, and Enemies. Ignored by own ability rays so you never target yourself.
Layer 9: Environment Static floors, walls, ceilings, and downhill speed ramps. Collides with everything. Default fallback for Grapple Slingshot tethering. Blocks LOS.
Layer 10: Interactables Crates, puzzle blocks, and launchable physics props. Primary target for Vacuum Snatch. Collides safely with player; acts as riot shield vs rapid lasers.
Layer 11: Hazards Bottomless pits, kill planes, and laser tripwires. Trigger colliders. Touching a laser or pit resets player or halts slide.
Layer 12: Enemies Enemy bodies and hurtboxes (Swarmer, Hulk, Sniper, Sentry). Targeted by Wind Blast and Crate Cannon. Swarmers can be grabbed and launched.
Layer 13: Projectiles Incoming sniper rounds, rapid laser bolts, and rockets. Sniper rounds deflect with Push (`LMB`); rapid lasers absorb into held crates.
Layer 14: GrappleAnchors Dedicated aerial swing rings and grapple points. High-priority grapple targets for aerial slingshot traversal.
